# 🌳 FamilyTree

Ett fullstack-projekt för att skapa, utforska och bevara familjehistoria genom interaktiva släktträd.

Projektet består av en React-baserad frontend och ett ASP.NET Core Web API som tillsammans gör det möjligt att skapa personer, relationer och visualisera familjestrukturer på ett intuitivt sätt.

---

## 📖 Om projektet

FamilyTree utvecklades som ett examensarbete inom Systemutveckling .NET med fokus på:

* Modern webbutveckling
* REST API-design
* Databashantering med Entity Framework Core
* JWT-baserad autentisering
* Interaktiv visualisering av familjerelationer

---

## ✨ Funktioner

* Skapa och hantera släktträd
* Lägga till personer och relationer
* Visualisera familjestrukturer
* Hantera förälder–barn- och partnerrelationer
* Registrering och inloggning
* Responsiv design

## 🚀 Kom igång

### Klona projektet

```bash
git clone <repository-url>
cd FamilyTree
```

### Frontend

```bash
cd Frontend
npm install
npm run dev
```

### Backend

```bash
cd Backend/Backend.Api
dotnet restore
dotnet run
```
